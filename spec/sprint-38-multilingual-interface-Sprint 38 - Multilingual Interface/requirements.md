## Requisitos funcionales

R1. Los idiomas disponibles son exactamente `en`, `sw` y `so`.
R2. Cambiar idioma traduce navegacion, etiquetas de estado, niveles y recomendaciones predefinidas.
R3. Nombres de datasets, fuentes, valores, fechas ISO y API no se traducen.
R4. Una clave ausente usa ingles y registra warning.
R5. `validate_catalogs` falla si una clave obligatoria falta en un catalogo.
R6. El idioma no modifica valores numericos ni fechas del dashboard.
